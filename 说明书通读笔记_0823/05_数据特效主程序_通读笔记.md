## 5. 疑点 / 缺失 / 待核

1. **卡包真实定义数据源不明**：09_游戏数据/卡包 的 ScriptableObject 类只有 BoosterPackVisualItem（视觉）；Warpforge_code BoosterPackData.cs 是空壳；856 卡包数据定义在 03_卡牌（gen_spec_cards2.py）。**开包掉落权重/稀有度表**（原版"每包+1 传说/保底 200"的数值出处）建议查 `PackAssetProvider.cs` + 12_主程序资源 的 Pack/Preloaded data（本笔记未及，列为遗留）。
2. **GameObject 计数矛盾**：06 README 表 19237 vs 战斗预制体.md 正文 15734（应为取数范围不同：全部/去重根）。以 gen_spec_vfx.py 重跑口径为准。
3. **977 清单的"根级组件"列**：808 根显示 "-"（组件在子级），且清单不含子级粒子关键信息（Shapes/emission 等）——做具体 VFX 移植时必须读原始 GO 树（dump_card_vfx_tree.py / dump_scene_tree.py）。
4. **动画曲线没有"曲线←→组件"引用表**：148 个曲线资源名已全列，但哪个组件引用哪条（AnimFXModuleTween/UnitTweenSO 挂载点）需另做反查；且**动画曲线目录只有 148 条**——battle 单位动画（卡牌攻击飞行/落地）+ ScreenShake 的完整参数集在 VFX 预制体的 UnitTweenSO/CameraShakePresetSO 实例里（08_预制体特效 MonoBehaviour 5694 中），不在 09_游戏数据。
5. **运行时管理器 84 个里有 6 个是 UI 按钮材质**（EverguildButtonMaterialModifier，含"Button Text"×4/ButtonLeft/ButtonRight/Generic UI Button），并非管理器——84 是"带脚本的唯一 GO"口径而类只有 79 个。
6. **主程序 MonoScript 8906 vs 游戏数据 1444 vs Warpforge_code 1891**：三个口径（全量类文件/场景序列化类/去重 C# 源码）；确认类映射时应以 Warpforge_code（1891 .cs）为准，8906/1444 均含重复。
7. **VFX 清单无分类标签字段**（只有名前缀约定）；"UNUSED/OLD/REJECTED/Test" 变体仍有约 15 个会污染统计，接入时按注释排除。
