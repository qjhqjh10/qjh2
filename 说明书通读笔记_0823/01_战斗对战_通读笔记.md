## 1. 战斗规则权威条款（规则书全文_中文翻译.md，365 行）

> 出处行号均指该 md。摘要（战斗规则摘要.md）与之对应：energy/后手/手牌/攻击反击/护甲/关键词/教程 已挂 rule_core.gd + battle.gd。

### 1.1 基础概念（19-36 行）
- 阵营锁定 TCG；玩家操控**督军（Warlord）**，卡组以**部队（Troops）**为主、**战术（Stratagems）**支援。
- **战场（Battlefield）**：双方**玩家棋盘 = 9 个空格。督军永远占据中央格，两侧各 4 格共可部署 8 张部队卡**（= slotsPerSide 4，与项目记忆一致）。另有卡组/弃牌堆/持续效果堆/能量区/骷髅头。
- **能量（Energy）**：指示物代表，起始 1，每回合 +1（经典）。
- **骷髅头（Skulls）**：将敌方督军生命削减至 **20 / 10 / 0** 时（首次）各获得 1 个骷髅头（= 每局最多 3 个；对应 HUD Milestones `x3` 与 EndBattlePanel 3 个 skull）。
- **游戏模式**：
  - **经典（Classic）**：目标=敌方督军生命降至 0（同时 0 = 平局）；卡组=1 督军 + **1 防御卡** + 30 张阵营卡；**手牌=起手 3，上限 10，每回合抽 1**；**后手=开局多 1 张牌 + 持有防御卡**；**换牌（Mulligan）=可弃回任意起手牌重洗补抽**；能量=每回合开始 +1；**加时（Overtime）=后手玩家最大能量达 10 时进入，双方每回合抽 2 张**；组卡限制=普/稀/史最多 2 张、传说最多 1 张、全部与督军同阵营。
  - **遭遇（Skirmish）**：目标同经典；卡组=1 督军 + 1 防御卡 + **12 张**阵营卡；**手牌=起手 4，上限 8，每回合抽 1**；**换牌=不允许**；能量=每回合 **+2**、后手开局 +1、**回合结束未用完能量"保存"1 点 → 下回合最大能量 +1**；**督军生命全部比正常少 10**；传说最多 4 张（不含督军）。
  - **轮抽（Draft）**：随机 3 卡卡包选组卡，可用经典或遭遇规则。
  - ⚠️ 条款矛盾（记录待裁）：经典表"加时=后手最大能量达 10 进入、双方每回合抽 2 张"；§3 能量节（137 行）却说"**双方均达 10** 能量后进入加时：每回合 **+2 能量**直至游戏结束"。两处不一致，实施时需选一（建议以经典表+游戏实测为准，代码见 rule_core.gd 加时判定）。

### 1.2 卡牌类型（66-109 行）
- **卡牌→单位（Units，有攻击/生命，含督军与衍生物）/部队（Troops，仅部队卡不含督军）/战术（Stratagems，任何非单位卡含防御卡）/万能卡（Wildcards，可代替任何卡，指定后不可改）**。
- 作用于"**部队**"的效果**不能**影响督军；"**单位**"的效果**可以**影响督军。
- 卡面：近战攻击、远程攻击、生命、类型；战术无攻击/生命；费用 ≥ 0。
- 稀有度宝石色：灰=普通、绿=稀有、品红=史诗、金=传说、橙=防御/特殊。
- **督军**：定义阵营/初始生命/关键机制；**总是拥有天赋（Talent）——每回合开始加入手牌、回合结束移除的临时战术**。
- **部队部署**：可选择督军左侧或右侧空格；**优先紧邻督军**；可在两单位间插入（最外侧外移一格）；最外侧已满 4 格则部署到另一侧；8 格全满不能再部署。
- **使用**：部署当回合不能行动（除非迅捷/侧翼/狂暴等注明）；每回合每单位 1 次行动。
- **摧毁**：生命 ≤ 0 即被摧毁（部分卡可不造成伤害直接摧毁）；被摧毁触发效果（如反噬）**立即结算**，然后进弃牌堆。
- 战术=打出→结算→进弃牌堆；影响多单位时按单位部署顺序逐一结算。
- **防御卡（Defence）**：后手（防守方）可打出的特殊战术；**每个阵营有 3 张独特防御卡**（= 后手补偿的内容物之一）。

### 1.3 战前准备（115-123 行，顺序执行）
1. 部署督军 2. 分离防御卡 3. 能量设为 1 4. 确定阵营规则与货币（额外卡/指示物）5. 掷骰/硬币定先手 6. 先手取得**进攻卡（Offense）**；后手取得**防御卡（抽牌后置入起手牌）** 7. 洗牌放置 8. 双方同时抽起手牌（规则依模式）。

### 1.4 回合结构（125-134 行）
无传统阶段：① 结算"回合开始"效果 → ② 结算阵营能力 → ③ **能量**：按模式增加/重置 → ④ **抽 1 张** → ⑤ 以任意顺序打出部队/战术、用可用单位执行行动 → ⑥ 结算"回合结束"能力 → ⑦ 交给对手。

### 1.5 能量/目标/行动（136-156 行）
- 能量起始 1、每回合 +1；**通常不跨回合保留**（遭遇模式例外，存 1 点）；双方均达 10 → 加时（见 §1.1 ⚠️ 两种说法）。
- **目标选择**：有效目标 = 场上无"防止被选中"生效效果的单位；**若敌方棋盘上任何单位有先锋（Vanguard），则只能选中有先锋的单位**；部分卡指定敌方单位/敌方部队/友方部队；部分关键词使单位对特定攻击/战术无效。
- **行动**：每单位每回合 1 次（除非另有说明）；部分单位有**替代行动**取代攻击。
- **攻击**：选单位 → 声明攻击类型（近战/远程）→ 选有效目标 → 声明；伤害按声明类型**同时结算**。
  - 例：兽人小子（3 攻近战）打初生者：双方同时受伤（初生者 0 生命进弃牌堆；兽人小子 3→2）。
  - 攻击力 ≤ 0 的单位无法执行该类型攻击。
- **替代行动**：职责（Duty）/狂暴（Ferocity）/祈祷（Pray）等受与攻击相同限制；例：猎狼的狂暴=先触发一次攻击（阻止攻击也阻止狂暴）；震荡突击兵的职责即使无法攻击仍可激活。
- **抽空疲劳（Deck-out Fatigue）**：牌库抽空后每次尝试抽牌，督军受**疲劳伤害 = 自首次抽空以来的尝试抽牌次数**；**加回卡牌不重置**计数；"检索"特定卡的抽取**不触发疲劳**（先检索再抽取）。

### 1.7 问题机制（Problematic Mechanics，227-235 行）
- **临时卡**：天赋、伴生部队、带潮涌的复制（在手牌时）回合结束未打出即**从游戏中移除**（非弃置）；督军天赋每回合循环可反复使用。
- **属性减益**：可无限叠加，减到 0 以下**不视为 0**。例：2 近战被 -2 ×2 后为 **-2**，需至少 +3 才回正。
- **送回牌库**：从战场回牌库/生成加入牌库的卡应洗入（除非另有说明）。
- **抽特定类型**：从牌库抽直到匹配，入手牌或按说明部署，然后洗牌。
- **"选择"效果**：随机 3 张候选，玩家选 1 保留/抽取/结算；未选中的（若来自牌库）放回洗牌。
- **抽到即激活**（常见暗黑天使传送）：仅当回合从牌库抽到时触发；建议把卡面朝下放手牌旁记录。
- **费用增减**：用回形针/标签/笔记非破坏记录。

### 1.8 同时触发（Simultaneous Effect Triggers，237-238 行）
两个单位能力同时触发（如带斩杀的摧毁带反噬/不稳定的）：**被攻击方优先**结算其效果（效果按序列触发，与伤害不同）。序列：攻击 → 双方结算伤害 → 生命归 0 方触发效果 → 摧毁方触发效果。

## 4. 教程流程（6 关，from Warpforge_TutorialStage1-6.json 提取——补充自 09_游戏数据）

**数据管线（教程流程.md 权威）**：`09_游戏数据/教程/MonoBehaviour/Warpforge_TutorialStage{1-6}.json`（MonoBehaviour，字段 turnScriptedData）→ `scripts/build_tutorial_data.py` 清洗（删 `<link=..>`/`<sprite>`/`<nobr>` 富文本；`<br>`→换行；**关键词解析 中文 2-4 字符 vs 英文 8-13 字符，偏移/索引不同**，battle.gd `_fx_from_event`）→ `D:/warpforge/data/tutorial_stages.json` → battle.gd 按关+回合显示提示/校验动作。每关字段：`bg`(newBg_Tutorial)、`playerStarts`(1=玩家先 0=先手)、`playerDeck`/`aiDeck` PathID、`hideCemetery`/`hideCardsLeftInDeck`/`hideLargeCardDisplay`/`hideChat` 开关、`uniqueIdCampaign`；每回合 = turnName/scriptedTurn/dontDrawCard/dontDrawTalent + scriptedActions[]（actionType 字符串内嵌提示文本；`playerAction=1`=要求玩家完成该动作；`shouldHighlightElement=1`=高亮元素；textReference='TutorialN/TurnN/TipN' 本地化键；smallTipParams: positionReference/positionRelation/showLeftArrow/showRightArrow/tipDuration/waitForTip/tipWithContinue/preventSkipTip）。

**6 关内容（动作序列实况）**：
- **Stage1 星际战士（Ultramarines，玩家先手）**：① 介绍督军与进攻（拖拽攻击）→ 反击伤害 → 敌方反击 → END TURN 高亮；AI 攻击+问候；② 胜利条件（敌方督军生命 0 死亡判胜/我方先死死局）→ 敌方出 Reiver；③ 切换近战/远程模式（ChangeToMelee/ChangeToRanged）→ 远程打 Reiver → "选择攻击模式"；④ 每回合抽 1、手牌上限 8 → 部署 Intercessor（拖手牌上场）→ 新部署单位下回合才能进攻；⑤ 用 Intercessor 远程击杀 Reiver；⑥ 抽 3 张 → **打牌消耗能量："每回合能量回复并 +2"** + "未耗尽全部能量可累积 1 点，下回合 +1"（遭遇式能量规则！）→ 出 2×Reiver 自由攻击；⑦ 出 Devastator Centurion（6 费）→ 不必每回合进攻（"有时更明智的是按兵不动"）；⑧ 终结战。**注意：教程使用的手牌上限 8 与能量 +2/存 1 与规则书"遭遇模式"一致**（代码侧需按模式区分）。
- **Stage2 兽人（Ghazghkull，玩家先手）**：单位特殊能力（Makari 给相邻单位近战加成）→ 出 Makari；敌方 Firstborn/远程切换；**Tide（潮涌）**：同卡当回合多张（出 3×Grot）→ 天赋(Talent)当回合生成战术（dontDrawTalent=1 控制）→ **Mob（群体）**：友方近战后触发（Shoota Boy，高亮）+ ActivateHandCards + PlayerChoice（自由回合）→ 战术是瞬时效果（Grot Bomb）→ **Vanguard**（高亮）→ Talent 每回合造一张战术 + **Ephemeral** 回合结束消失 → 出 Slugga Boy×2 + Greatest Warboss → 终战自由操作。
- **Stage3 死灵（玩家后手 playerStarts=0）**：AI 先出 Warrior → **Remnant（残骸）**：被杀后留在场（高亮）→ 出 Relentless March → AI 出 **Reanimation Protocol** 复活残骸、部分部队**被复活时触发特效** → 残骸**存活到其控制者回合结束** → 出 Extermination Protocol/Gauss Warrior/Flayed One → 我方复活 → **Artifice（巧技）**：使用战术时触发（Technomancer，高亮）→ **攻击或伤害残骸会摧毁它**（高亮）→ Plasmancer 等 → 终战。
- **Stage4 黑军团（玩家先手，对手=极限战士 Tigurius）**：出 Chaos Legionary → 敌方 Octavio Infiltrator 远程 → **Dark Pact（黑暗契约）**：给部队贴契约后触发伤害（高亮）→ 四系契约逐个教学：**鲜血(Khorne)**=+2 近战+先锋；**纵欲(Slaanesh)**=+2/+2（督军受伤时获得）；**韧性(Nurgle)**=+1 生命+再生；**命运(Tzeentch)**=+2 生命+伪装 → **多个契约可叠加** → **脆弱（Vulnerable）**（高亮）→ **猛击（Strike）**攻击后触发（Possessed Champion 高亮）→ 按契约数量增幅（Skeins of Fate）→ 终战。
- **Stage5 灵族（玩家先手，对手=死灵）**：出 Windrider → **星镖（Shuriken）**：结算攻击伤害前先造成额外伤害；**若此伤害击杀目标则无反击**（两处高亮；"仅攻击时触发"）→ 近战切换 → Striking Scorpion → AI 复活流 → **路标石（Waystone）+ 灵魂石（Spirit Stone）**：带 Waystone 单位被毁掉石 → **TapCard 点击灵魂石收集**（高亮）→ **HUD 计数（SpiritStoneHolder）**（高亮）→ 部分卡消耗灵魂石触发额外效果（Vengeful Wraithblade 高亮）→ Banshee Mask/Swooping Hawk → AI 攻击会摧毁灵魂石（高亮）→ 部队与战术都能消耗灵魂石（Witchfire 高亮）→ 终战。**Viorla/灵族 2D 层灵魂石 holder 在场景中 inactive，教程/战斗中动态启用——复刻时需支持动态开启。**
- **Stage6 泰伦（玩家先手，对手=极限战士 Uriel Ventris）**：出 Brood Progenitor → Termagant/Spore Mine → **虫群（Swarm）**：同名部队打到**场上同名部队左侧**合并属性（高亮；**直接打别的位置不会合并**，两处高亮）→ 出 Lictor → 突触前奏 → **突触（Synapse）**：战术效果转移给相邻单位（Tyranid Warrior 高亮）→ 部分部队在触发突触时提供额外效果（Zoanthrope 高亮，Adrenal Surge）→ "杀死它打破突触链接"（AI 台词）→ 终战。

**教程相关 UI（2D 树）**：TutorialObjs 四标签+箭头、TutorialTip 气泡（Test tutorial tip）、TutorialArrows×2、InitTutorialTip、TutorialPointerCombat、SkipTutorial 按钮（设置面板内）、TutorialController。**SkipTutorial 按钮与教程关卡耦合于 battle.gd _tutorial。**
