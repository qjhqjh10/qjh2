**关键规律**：
- **变体体系**：Game 的设计是把"同类元素"做成一个预制体 + 多个 Variant（Variant=动画/换肤/换子元素组合）。313 根里真正"独立功能界面"约 110 根，其余是（a）变体（如 24 个 General Basic Offer Popup Variant 共享同一布局）、（b）容器/抽屉子组件（Content [604,0 712x1080] 三栏右侧抽屉家族约 25 根，全部同构：Background+Image+Label+Converted/Ephemeral Drawer+Collected Badge+Army）、（c）小工具件（Timer/Price Display/Checkbox/Dropdown/按钮底）。
- **商店容器分层**：3509x125 阵营选择条（Army Selector）→ 主题 Tab（左 165 宽竖栏）→ 内容区（1756x1080）→ 商品容器 3 种尺寸（339×778 主卡 / 339×389 小卡 / 220×356 格子卡 / 391×930 大卡）。
- **多语言残留**：原文大量西语/葡语/俄语（"Ruta Gratuita"/"Clique para continuar"/"Новинка!"），复刻一律用 JSON 英文或与原版一致。
- **inactive 标注**：`(inactive)` 表示场景中禁用的分支（如 Alternate Art 页、登录窗、已购 Badge、Ephemeral/Converted 抽屉）——复刻时大部分不用铺。

## 四、与项目对照的方法学备忘

- 项目场景 40 个（scenes/*.tscn）+ 126 个脚本。**很多原版"根界面"被合并进一个大 tscn**：rewards.gd=任务中心（4 键+3 内容嵌入实例 quests/campaign/forge）、main_menu.gd=主菜单+聊天+玩家资料入口、player_profile.gd=6 标签页（内嵌 Achievements/排行榜/战斗记录）、shop.gd=3 个商店变体 Tab、ranked.gd=排位 2 变体。
- 对照时**先看功能是否可达**（某弹窗/页面能否从导航到达），再看是否按原版坐标复刻（后者是审查代理的事）。
- 单机化剔除范围（说明书中联机/内购/服务端功能，复刻单机版不需要或应简化）：XSolla/WebShop 支付、登录/注册/改密（ChooseNameWindow 保留改名）、决斗挑战、实时聊天发送、联盟创建/邀请/排行刷新、Season/Last season 排行、Raid/Expansion Pass（本赛季运营活动）、Sunset 转生公告、InApp 购买。
